# Acceso movil y uso compartido de MindCare

## Enlace de demostracion

La demostracion publicada se consulta en:

`https://mindcare-api-3n16.onrender.com`

La aplicacion web y la API se sirven desde el mismo origen HTTPS. Cada persona debe crear su propia cuenta y aceptar el consentimiento informado.

## iPhone y iPad: instalar como PWA

1. Abre el enlace en **Safari**.
2. Inicia sesion o crea una cuenta.
3. Pulsa **Compartir**.
4. Selecciona **Agregar a inicio**.
5. Confirma el nombre **MindCare**.

Safari crea un acceso de pantalla completa con el icono de MindCare. No requiere USB, App Store ni instalar un APK. La sesion y los datos se consultan mediante HTTPS mientras el dispositivo tenga conexion.

## Android

Hay dos alternativas:

- Abrir el mismo enlace HTTPS en Chrome y seleccionar **Instalar aplicacion** o **Agregar a pantalla principal**, cuando el navegador lo ofrezca.
- Instalar el APK de demostracion generado por Flutter en un dispositivo Android. El APK no es compatible con iPhone.

## Compartir con otras personas

- Comparte solo el enlace HTTPS, nunca las credenciales de administrador, psicologo ni las variables de Render.
- Cada persona debe utilizar un correo propio y una contraseña diferente.
- Los psicologos asignan las citas desde su panel; el usuario puede consultar al profesional y sus citas asignadas.
- La plataforma es apoyo de seguimiento y no sustituye una atencion de urgencia o diagnostico profesional.

## Alcance de la publicacion

La modalidad PWA permite la demostracion en iPhone y Android sin una cuenta de desarrollador de Apple. Una aplicacion nativa iOS distribuida por App Store requiere macOS, Xcode, firma de Apple y la cuenta de desarrollador correspondiente.
